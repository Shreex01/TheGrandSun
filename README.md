# The Grand Sun

A React and Vite starter for a thoughtful online learning marketplace. Browse classes, filter by topic, save choices to a cart, try the demo checkout, and revisit purchased classes in the learner view.

## Get started

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — check the project with Oxlint

## Starter-project notes

- Cart selections and demo purchases are saved in browser local storage.
- Course prices are displayed in Indian rupees (INR).
- Checkout is for demonstration only. It does not process or store payment details; connect a payment provider before accepting real payments.
- Course photos and the sample lesson video are remotely hosted placeholders. Replace them with your own licensed imagery and uploaded course media.
- Footer social links currently point to platform homepages. Replace them with The Grand Sun’s official profile URLs.
- A production course marketplace will need a backend for accounts, course content, orders, and payment processing.
